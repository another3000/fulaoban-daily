传阅闸门：一人回执不等于决策链已阅

2026.11.11

周三 · 上海

对照计划 · 第1个月第1周 · 定位与报价 · 课次18 · 催交传阅闸门 · 不硬开第2周

作业回看 · HOMEWORK CHECK

今天仍无可批作业。昨天「回执闸门」催对方书面点名三句绿句，纸仍空（即便你今天一并交出首发包和回执条，也还没有决策链上第二个人书面已阅）。七格全红灯空：①L1结果包 ②L2决策链 ③L3三档菜单 ④L4止损/让步 ⑤L5里程碑+人情 ⑥一页上场版 ⑦证据包P1～P4。今日课题不是重开回执细则 / 首发仪式 / 出门证三绿，而是给回执加一把「传阅闸」——一人回执不等于决策链已阅。没首发就谈不上回执，没回执就谈不上传阅。第1周须闭环；今天禁止硬开第2周。

社论导读 · EDITORIAL

昨天把回执闸拍在桌上：首发离厂不等于对方收下，要书面点名三句绿句。「嗯」「收到了」「回头再对」不算回执。今天是周三。即便你已经要到了小李的点名（更多人连首发包都还没交），下一个自我安慰会准时上门：「小李已经看过了，回头他跟老张说说；他说已经转了，我等消息就行。」周三上午小李不会主动把三句绿句抄送给主任和设备科，他会回：「我看过了，没大问题，回头我跟老张说说。」或者：「我已经转了，你等消息。」或者更防你一步：「别直接找主任，我内部同步就行。」这句话听起来像院内已经对齐，实际是在用「一人转述」冒充决策链已阅：牌底是老张会上可以说「这三句我没看过」。

「小李说他会转」写在你的自我安慰里，对老张会上改边界、对小王不认触发，等于零。咨询公司有 Circulation Gate / Stakeholder Routing（传阅闸 / 干系人路由），企业软件有 Buying Committee Alignment（采购决策链对齐）：冠军用户点了头，不等于经济买家和付款人已经看过范围句。今天不重开已讲过的定位细则，只加一把闸：一人回执之后，要决策链上第二个人书面已阅三句绿句。一人回执不等于决策链已阅；没传阅，就别假装院内已经对齐。

「一人回执 ≠ 决策链已阅；没传阅，就别假装『院内已经对齐』。」

— 亿万富翁导师 · 本周金句

今日课题 · BRIEF

传阅闸门（Circulation Gate）——一人回执之后，要决策链上第二个人书面已阅三句绿句。为 LIS 或输血标准档至少一线：①若仍无首发包，今天先交三绿最小包；②若仍无回执，补回执条（书面点名至少两句；「嗯 / 收到了 / 回头再对」不算）；③再交「传阅条」——按 L2 写出拍板 / 影响 / 付款具名名单（没有 L2 就今天补黄灯名单）；至少两名被点名人且不能只传小李，必须有老张或经济买家，绿句含付款触发则小王也须在列；④传阅走小李路由，用群 / 邮件抄送 / 转发截图留下收件人，且除小李外至少一人书面已阅。禁止把「回头说说 / 已经转了你等消息 / 内部同步就行」当传阅。输血纸不可把「迎检通过」写成收款开关；勿编假财报、勿抄示例。交了红笔批；没交则 homework 继续 pending，第2周继续锁。角色照旧：信息科小李、主任老张、设备科小王。

拷问：小李回「回头我跟老张说说 / 已经转了你等消息 / 别直接找主任」——你把它当院内对齐收下，还是请他按名单传阅并留下第二人已阅？

轻量硬理论 · Circulation Gate / Stakeholder Routing

Circulation Gate＝事先约定的「范围句必须按决策链名单被第二人以上书面已阅」检查清单。Stakeholder Routing＝文件不靠冠军用户口头转述，而靠可指认路径到达影响者和经济买家。四条：①一人已阅≠院内已对齐，进度靠「名单上第二人留下已阅痕迹」证明，不靠「他答应回头说说」；②口头转述≠传阅，buying committee alignment 必须落到具名收件人和书面已阅；③冠军用户不是经济买家——小李常是入口和路由，老张影响专业边界，小王卡住付款触发；④传阅是变更的前置：后面改边界走的是「已阅之后的变更」，不是「这材料我没看过」。十来人厂没有售前军团擦屁股——你更需要传阅闸。第2周大理论等首发包、回执和传阅交上来后再开。

世界500强 / 顶级售前 · 可偷的纪律

咨询公司把「文件按名单传阅并收回已阅」当上会纪律：只有冠军用户 acknowledge，不许对外说「客户侧已经对齐」。企业软件售前有 stakeholder review / buying-committee circulation：经济买家和付款人被点名已阅之前，实施不许按「信息部门说没问题」开工。医疗信息化更碎：小李一回「回头我跟老张说说」，你若没有传阅条，老张会上改边界，小王事后说「触发句没人传给我」——你只有一个「小李说他会转」。传阅是给小李减责用的，不是你在越级——今天交传阅条，是帮他少一次会上一个人挨问，也是阻止「回头说说」被改写成「他们都知道了」。

亿万富翁致富经

小老板怕要传阅，觉得小李都点头了再点名老张和小王太越级。富老板把传阅当廉价保险：交卷成本是今天写出传阅条（名单+请小李转发+要第二人已阅）；不传阅成本是老张会上说「我没看过」、小王不认触发，你只能说「可是小李说他会转」——这句话在院长桌上等于零。你本人就是标准档口径传到决策链的唯一责任人。纸可以黄，传阅不能用「回头说说」代替。致富算术：传阅闸暴露「一人回执＝院内对齐」→今天交传阅条并要第二人已阅→对外不裸体；跳过传阅→口头转述出门→人情与改口替你填空。

行业落地 · 传阅条（今天出门）

角色照旧：信息科小李、主任老张、设备科小王。按真实院况填；比例勿编假财报。

① 首发 + 回执在先

今日最低：先交三绿最小包首发；回执须书面点名至少两句（或「三句均已知悉，待补见页脚」）。还没有就空要传阅＝未达。

② L2 名单

今日最低：写出拍板 / 影响 / 付款对应的真实姓名（可黄灯占位，但必须具名）。不写或只写「院里相关领导」＝未达。没有 L2 就今天补这一格。

③ 传阅范围

今日最低：至少两名被点名人，且不能只有小李；必须有老张或经济买家；绿句含付款触发则小王也须在列。只传小李或「内部同步就行」＝未达。

④ 可转发证据 + 单点处置

今日最低：群、邮件抄送或转发截图能看见收件人；除小李外至少一人书面已阅。24 小时仍单点则请转第二人；48 小时仍单点则交「决策链未阅」记录。「回头说说 / 已经转了你等消息」＝未达。

判定：有首发包+有回执+名单具名+除小李外至少一人书面已阅→今天算过传阅闸；只有小李回执或「回头说说」→禁止把一人转述当成院内对齐。

虚拟院：小李周三上午回「回头我跟老张说说 / 已经转了你等消息 / 别直接找主任」——你若把这句当传阅，会上老张说「这三句我今天才听见」，小王说「触发句没人传给我」，压力转成你再讲一遍。掏出传阅条：「李哥，内部同步我听您的，我不直接找主任。请按名单把三句绿句转给老张（和名单上的小王）点一下已阅。这样会上不是只有您一位对过口径。」传阅挡一人转述；没传阅只能赌小李的记忆。传阅走小李路由，不私下绕过他去戳主任。输血绿句可写合规闭环怎么验收，不可把「迎检通过」写成收款开关。

今日必做 · DO TODAY

1. 若仍无首发包：今天先交三绿最小包首发。没首发就谈不上回执和传阅。
2. 若仍无回执：写出回执条，要对方书面点名至少两句；禁止「嗯 / 收到了 / 回头再对」。
3. 写出「传阅条」：补上 L2 具名名单；至少两名被点名人且不能只有小李；必须有老张或经济买家；绿句含付款触发则小王也须在列。
4. 传阅走小李路由，用可转发渠道；除小李外至少一人书面已阅。禁止把「回头说说 / 已经转了你等消息 / 内部同步」当传阅。
5. 24 小时仍单点发一次请转第二人提醒；48 小时仍单点，交「决策链未阅」记录。
6. LIS 或输血至少一线；输血勿迎检当收款开关；勿编假财报、勿抄示例。
7. 今日下班前交首发包（若还没有）+ 回执条（若还没有）+ 传阅条到聊天或邮件附图。没交 → pending，不进第2周。

拷问：小李回「回头我跟老张说说 / 已经转了你等消息」——你把它当院内对齐收下，还是请他按名单传阅并留下第二人已阅？

厚黑人情 · 老油条 · HOUHEI

对方回「回头我跟老张说说」「我已经转了，你等消息」或「别直接找主任，我内部同步」

本课角度：绑传阅闸门 / Circulation Gate / 一人回执不等于决策链已阅。小李说「回头我跟老张说说 / 已经转了你等消息 / 别直接找主任」——牌底是用一人转述代替决策链已阅。合法可试。禁止行贿、回扣、假票、围标。

一句招 · 一句戒

招：「李哥，内部同步我听您的，我不直接找主任。另外请您按这份名单把三句绿句转给老张（和名单上的小王）点一下已阅：已读哪几句、有无异议写哪句。这样院长会上被追问标准档边界时，不是只有您一位对过口径，省得当场对不上再开一次返工会。」把传阅译成帮小李省院长会上一个人挨问。

戒：永远不要把「回头说说 / 已经转了你等消息 / 内部同步就行」当成传阅；也永远不要为了要第二人已阅就绕过小李私戳老张——前者把对齐权交给对方事后的改口，后者把入口人变成对手。可以让他选渠道，不能一边说院内已经对齐，一边接受一句「你等消息」。

讨论靶场 · DEBATE

反向角度：有人说「只要小李回执就行，再点名老张和小王是越级、伤感情，他内部同步以后再改也一样」——你何时同意、何时硬刚书面传阅？用真实被「入口人说已经转了、会上主任却说没看过」套住的一单说明：当时若有传阅条点名了第二人已阅哪两句，哪一句能挡住院长追问？（引导：关系越好越要走入口人做路由，把已阅摊到决策链上；「以后再改」会改成对你不利的版本。）

靶向（行业深挖）：传阅名单最小该有谁？A) 小李回执就够；B) 小李+老张双阅；C) 绿句含付款触发时必须把小王也列入。用 LIS 或输血举一例：小李只回「回头我跟老张说说」而老张会上改边界时，你怎么用传阅条挡、又不显得越级？若先发输血线，如何避免把「迎检通过」写进绿句/传阅条当收款开关？

开拓风暴 · STORM · 周三完整 A/B/C

微生物室·培养阳性分级预警与临床沟通记录

培养转阳之后，按病原分级把预警送到管床医生，并留下「谁在何时如何通知、对方是否回呼」的沟通记录。夜班漏打电话、医生在台上没回、第二天口口相传「好像通知过了」，是普遍痛点。AI 吃分级草稿、通知话术与未回呼清单；更值钱：分级规则由谁签、渠道授权、沟通记录谁审、谁付费、人审边界。不碰 LIS 核心报告结论，不碰发血决策，不抢主线回款。这一刀不是危急值闭环、报告时效、外送回传对账、交叉配血时效 SLA、标本转运，也不是昨天的手术室耗材近效期钩子——只盯培养已经转阳、通知还在路上、记录对不上的那一段。

路径 A · LIS 旁路「阳性分级预警 + 沟通记录导出」

起步：现有 LIS 复用微生物结果与通知通道，加分级、通知记录、未回呼清单、周报导出。赚钱：院年费或模块加购。冲富：中（复用部署可复制，票面多为加购）。陷阱：被拉去全院消息中台或替换危急值主流程；分级规则扯皮——写进含/不含，付款走里程碑，不绑「阳性零漏通知」或「替代医生判断」。与主线：可接加购；勿抢回款。

路径 B · 轻 SaaS：预警推送与沟通台账（不写入 LIS 报告）

起步：录入或只读接口接入阳性条目，向管床医生推送分级预警，记录回呼/未接，输出沟通台账；不写入 LIS 报告、不碰发血。赚钱：订阅+超量科室包。冲富：中高（不全靠单院招标）。陷阱：被当成官方必达通知认证或漏通知自动问责；隐私与医生手机号翻车——须授权书/审计/免责；无权限模型别规模化。与主线：分队；勿抢回款。

路径 C · AI 读培养本/微信通知/电话备忘生成「未回呼周报」草稿（更野）

起步：AI 批量读培养登记本照片、微信群通知、Excel 或电话备忘，出「本周阳性未回呼+疑似分级」草稿，人审出门。赚钱：项目制+抽检费或与A/B捆绑。冲富：高（附高风险）。陷阱：幻觉错怪医生、培养结果读错、被当成自动问责；禁止宣称「AI已认定谁漏通知」。与主线：严格分队；主线未回款勿抽核心实施清照片。

选边：90 天只押 A/B/C 哪条？回聊天；写首笔收款触发证据一句；若会抽走补传阅条与作战纸时间——先交首发包+回执条+传阅条，再开风暴。AI 可起草传阅条与预警目录，定稿前须你本人删掉「保证迎检通过 / AI已认定漏通知 / 保证阳性零漏通知」。
