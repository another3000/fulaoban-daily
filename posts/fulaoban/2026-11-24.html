范围锁定闸门：进场了不等于范围锁死

2026.11.24

周二 · 上海

对照计划 · 第1个月第1周 · 定位与报价 · 课次22 · 催交范围锁定闸门 · 不硬开第2周

作业回看 · HOMEWORK CHECK

今天仍无可批作业。上一堂落地的课是昨天周一的「进场闸门」：有纪要不等于可以进场开工，要书面合同或等值采购文件（含或附三绿）、首款证据和进场范围、日期与授权人。纸仍空（即便你今天一并交出首发包到进场条，也还没有双方确认的含/不含清单和「变更另单另价」原句）。七格全红灯空：①L1结果包 ②L2决策链 ③L3三档菜单 ④L4止损/让步 ⑤L5里程碑+人情 ⑥一页上场版 ⑦证据包P1～P4。今日课题不是重开进场细则 / 纪要闸门 / 上会闸门 / 传阅闸门 / 回执闸门 / 首发仪式 / 出门证三绿，而是给进场令加一把「范围锁定闸」——进场了不等于范围锁死。没首发就谈不上回执，没回执就谈不上传阅，没传阅就谈不上会，没上会就谈不上纪要，没纪要就谈不上进场，没进场令更谈不上把现场需求写成免费工时。进场令还没有，也要先交预置版范围锁定清单，而且今天不扩展范围、不接「顺便做一下」。第1周须闭环；今天禁止硬开第2周。

社论导读 · EDITORIAL

昨天把进场闸拍在桌上：没有含三绿的合同（或等值 PO）、首款证据和书面进场授权，就别派人，更别把「先调研 / 先搭环境」当成不算开工。「纪要都写了你先派人」「章还在走」「财务在走你先开工」「先派人体现诚意」不算进场令。今天是周二。自我安慰不会隔夜消失。即便你还没派出一个人（更多人连首发包都还没交），下一个请求也会准时上门；若已经有人在路上或在现场，它来得更急：「人都来了，顺便把危急值短信也做了。」「细节进场再商量，先把流程跑起来。」「这不都是 LIS 该有的吗，合同写的就是系统建设。」「就改一个接口，不算变更。」「先做起来，范围清单回头补。」

周二上午几乎是标准剧本。小李发来一句：「测试账号都开了，你们人不是已经来接环境了吗，老张希望把微生物和危急值一起做了，别让检验科觉得你们只做半截。」老张补一句：「标本流程既然在跑，危急值通知和微生物阳性推送也是检验科日常，一起做省得再上会。」小王再防你一步：「合同写的是 LIS 系统建设，这些功能本来就该有，别搞得像在另开一张单。」这句话听起来像配合、效率和现场优化，实际是在用「已经进场」冒充范围确认。牌面是人都来了、别浪费、别伤科室感情；牌底是 L3 菜单上的「不含」会在现场被一口一口吃掉，变更没有另单另价，验收时对方会说「当时你们都做了，怎么现在才说不含」——你口袋里也许有一纸进场令，甚至首款已到，可范围解释权已经跑到现场那一边。

有人会自我安慰：「软件实施本来就要现场对细节，进场了还锁范围是不信任，伤感情；小改不算变更，不顺便做就会丢掉科主任的支持；清单后补也一样，先把活干起来才像合作。」咨询与企业软件交付有一条铁纪律叫 Scope Lock / Scope Baseline（范围锁定 / 范围基线），后面紧跟着 Change Control（变更控制）：进场授权回答的是「谁让你来、哪一天来、先做合同里的哪一段」；范围基线回答的是「这一段里，含什么、不含什么，多出来的怎么计价」。你要偷的不是对方的变更流程软件，而是纪律：

「已进场 ≠ 范围锁死；没有双方确认的含/不含清单和『变更另单另价』原句，就别把『顺便做一下』做成免费工时。」

— 亿万富翁导师 · 本周金句

今日课题 · BRIEF

范围锁定闸门（Scope Lock Gate / Scope Baseline / Change Control）——进场之后，要书面范围令：双方确认的含/不含清单（对得上合同或三绿）+「变更另单另价」原句 + 确认人与日期

为 LIS 标准档或输血标准档至少一线：
1. 若仍无首发包：今天仍须先交「三绿最小包首发」。没首发就谈不上回执，更谈不上传阅、上会、纪要、进场和范围锁定。
2. 若仍无回执：补回执条，对方书面点名至少两句绿句；禁止「嗯 / 收到了 / 回头再对」。
3. 若仍无传阅：补传阅条，不能只传给小李，除小李外至少一人书面已阅；禁止「回头说说 / 已经转了你等消息」。
4. 若仍无上会：补上会条五格；禁止「等开会再说 / 我提一嘴 / 已经排上了你等通知」。
5. 若仍无纪要：补纪要条五格（会名日期、原句含或附三绿、决议性质、会后责任人期限、可转发摘录）；会尚未开先交预置版纪要条；禁止「原则上同意 / 先做起来 / 我口头跟你同步」。
6. 若仍无进场条：补进场条五格（合同或等值 PO 含或附三绿、首款到账或请款已受理证据、进场范围与日期、授权人、可转发文本）。合同未盖章或首款无证据：交预置版进场条件清单，不派人。禁止「纪要都写了你先派人 / 章还没盖先做 / 财务在走你先开工 / 先调研不算开工」。
7. 再交「范围条」五格：①进场令索引（合同或 PO 编号 + 进场日期 + 授权人；若尚无进场条，须先补进场条或预置版，范围条可同时交预置版，但今天不扩展现场工作）；②锁定范围原句（含什么、不含什么，必须对得上合同或三句绿句；禁止「先把流程跑通 / 按现场需要调整 / 系统建设所涉功能」这种空筐）；③变更规则原句（须写明：口头加项、群里一句话、科务会上「顺便提一句」均不算变更生效，须另单另价并书面确认）；④双方确认人与日期（至少小李 + 我方项目负责人具名；若范围触及检验科或输血科日常，老张须书面已阅）；⑤可转发文本（签字或邮件确认的范围清单；「进场时口头对过 / 会上说过 / 合同里都有」不算）。
8. 禁止把「人都来了顺便做一下 / 细节进场再商量 / 这是原合同里应该有的 / 先做起来范围后补 / 就改个小接口不算变更」当成范围已锁定。无进场令：今天交预置版范围锁定清单，不派人、不扩展范围。若已经有人在现场：今天补交范围条；48 小时仍停在「细节再商量 / 顺便做一下 / 这都该有」则交「已进场未锁范围」记录，并按 L5 逾期动作执行（能停则停新增项，不再靠人情加功能）。
9. 路由仍走小李，不绕过入口人去找老张或小王「私下答应加一项」。LIS 或输血至少一线；输血勿把「迎检通过」写进含项、变更条件或收款开关；勿编假财报、勿抄示例。
10. 交了红笔批；没交 → homework 继续 pending，第2周继续锁。L1～L5 + 一页上场版 + 证据包继续催交。

拷问：小李回「人都来了，顺便把危急值也做了，细节进场再商量，这不都是 LIS 该有的」——你把它当范围确认收下并开工加项，还是请他书面确认含/不含清单和「变更另单另价」？

商学院硬理论 · Scope Lock / Scope Baseline / Change Control

Scope Lock（范围锁定）= 事先约定的检查清单：「进场动员之后，必须再拿到双方确认的范围基线，才能把现场工作展开、把新增项做进交付」。Scope Baseline（范围基线）是被正式批准的「这一版含什么、不含什么」，不是实施工程师在现场用经验补出来的理解。Change Control（变更控制）= 基线之外的需求，必须走变更请求：写清加什么、验收怎么改、价格和工期怎么调，双方签字后才生效。工程里这叫签证或 Variation Order；咨询和系统集成里这叫 Change Request / Change Order。

这里要把三件事拆开，不能缩成一句「人都来了你顺便做」：

Mobilization / Kickoff（进场动员） 回答：谁书面同意你哪一天来、先做合同里的哪一段？证据是昨天的进场条。
Scope Baseline（范围基线） 回答：这一段里，含哪些可验收结果，哪些明确不含？证据是对得上合同或三绿的含/不含清单，以及双方确认人与日期。
Change Order（变更单） 回答：多出来的那一项，谁批准、另开哪张单、如何计价与验收？证据是另单另价的书面原句，不是群里一句「那就加上吧」。

把进场动员直接当成范围确认，再把范围确认省略成「现场边做边补」，咨询公司管这叫 scope creep（范围蔓延）——听起来像灵活，算出来是免费工时。更糟的是解释权会跑到已经进场的那一边：你做过的，很难再收进菜单「不含」；你没做过的，对方会说「人都来了，怎么还没有」。L3 的边界会在现场被人情一口一口吃掉，L5 的里程碑会变成「做完再说」，首款即便到了，也会被加项耗光。

世界500强 / 顶级售前实战（可偷的纪律）

Accenture、IBM GBS、Deloitte 咨询条线，普遍把 Scope Baseline + Change Control 写成交付政策，不是项目经理的个人脾气。开工会可以开，顾问可以进场，可一旦要在 SOW 之外加工作坊、加接口、加报表，就要进变更委员会或变更日志：写清影响、报价、工期，客户授权人签字，才能排工。有团队试过「人已经在客户现场，先把这个小需求做了，变更单后补」，结果是「小需求」连成两周免费开发，验收时客户说这些都是原范围——后来只能把损失记进交付成本，再在内部检讨为什么破了闸。

工程承包更硬。FIDIC 和国内总包惯例里，开工令从来不是「现场口头指令自动纳入原合同」。业主要加一项，须发变更令或签证，单价和工期另行约定。软件集成没有监理章，就更容易被一句「人都来了顺便做一下」骗进去。你要偷的不是对方的流程软件，而是这句纪律：进场归进场，范围必须另有书面基线；基线之外必须另单另价。没有双方确认的含/不含，没有变更原句，就没有新增项。

亿万富翁致富经

十来人厂第二种常见死法，不是进不了场，是进场之后不会锁范围。「人都来了顺便做一下」听起来只是一个接口、一张报表、一条短信，可对十来个人的厂，这就是把标准档拆成一单说不清边界的人情交付。你昨天若已经守住了合同和首款，今天仍可能把赚到的那一点确定性，交回给现场的「再加一点」。菜单上的「不含」一旦在现场做过，验收时就不再是「不含」，而成了「你们当时都认了」。

关系越好越要过这道闸。老关系最容易说出「细节进场再商量」「这都是系统该有的」。你给面子先做，就是把 L3 的定价权留在现场，把变更解释权留给对方。范围闸不是冷淡，是保护双方：小李不用为「合同里到底买了什么、为什么又加了这些、谁答应免费做的」挨问，你不用为没有变更单的工时和范围改口买单。十来人的厂经不起一次「顺便做」——那不是优化实施，那是把可卖贵、可复制的标准档，做成一单边做边涨的垫资人情。

行业落地 · LIS / 输血 / 十来人厂

继续用固定虚拟院角色演，不换行业：信息科小李、检验科或输血科主任老张、设备科小王。

剧本很常见。进场条刚有（或人已经在接测试环境），小李微信过来：「人都来了，老张希望把危急值短信和微生物阳性推送一起做了，别让检验科觉得你们只做半截。细节咱们进场再商量，合同写的是 LIS 系统建设，这些本来就该有。」老张补刀：「标本流程既然在跑，这两项也是日常，一起做省得再上会。」小王再加一句：「就改一个接口，别另开一张单，院里变更流程慢，先做起来回头补。」

你的动作不是翻脸，是走小李路由，出示预置版范围条（就是范围条五格），请他协调：含/不含清单对得上合同或三绿、写明变更另单另价、小李与我方负责人（必要时加上老张）书面确认。不绕过他去找老张私下答应加一项，不自己起草「我方理解原合同已包含危急值与微生物」群发。你可以这样说清利害：「现场先做哪一段听您的，我按锁定的含项派人；没有这五格，我在现场把危急值和微生物做进去，院长要是问合同里到底买了什么、为什么又加了这些、谁答应免费做的，您也不好答。」

若先走输血线：锁定范围只写合同里的系统建设、交接和验收条目，不要把「迎检通过」「保障用血安全」写进含项、变更条件或收款开关。迎检是医院的合规责任，不是你厂的到账款开关，更不是现场加项的理由。科主任希望「顺便把发血审核也改一改」，一律走变更条，不走人情。

厚黑人情 · 老油条

本课角度：绑范围锁定闸门 / Scope Lock Gate / 进场了不等于范围锁死。小李说「人都来了顺便做一下 / 细节进场再商量 / 这都是 LIS 该有的 / 先做起来范围后补 / 就改个小接口不算变更」——牌底是用进场事实和科室人情，代替含/不含确认与变更单。合法可试。禁止行贿、回扣、假票、围标。

一句招：把「请先书面锁定含/不含、加项另单另价再开工」译成「帮小李省院长事后问『合同里到底买了什么、为什么又加了这些、谁答应免费做的』时对不上口径」——范围条不是你在指挥检验科和设备科，是给入口人准备可出示的范围痕迹。他只需协调五格，不必在事后一个人扛「是我让他们顺便做的」。

一句戒：不要把「人都来了顺便做一下 / 细节进场再商量 / 这是原合同里应该有的 / 先做起来范围后补 / 就改个小接口不算变更」当成范围已锁定。没有双方确认的含/不含清单和「变更另单另价」原句，就是还没过闸。也不要自己先在现场把加项做了再补清单——活一做，再要另单另价和守「不含」，你已经没有谈判筹码。更不要绕过小李直接找老张或分管院长口头答应加功能，那是砸入口人的院内面子，把盟友变成对手。

可立刻试：今天写范围条时，把这句招抄在页脚当备用。上午若真有人回「人都来了顺便做一下」或「这都是系统该有的」，直接用，不靠临场灵感：

「李哥，现场先做哪一段听您的。为了避免院长事后问合同里到底买了什么、为什么又加了这些、谁答应免费做的，请帮我备齐范围条五格：进场令索引、含/不含清单（对得上那三句绿句或合同原句）、写明变更另单另价、您和我方负责人（必要时加上张主任）书面确认。您把这五格点一下，我按锁定的含项做，不在现场把范围做成对您不利的版本；要加的项，我们另开一页，价和验收另写。」

关系越好越要走他做路由。催的不是「拒绝给科室做」，是「别让他在没有书面基线的情况下，把你的人变成免费加项的工具」。对方事后若改口「这些本来就该有 / 当时只是先做起来看看」，你手里有含/不含原句、变更规则和确认人，比一句「他叫我顺便做的」硬得多。

讨论靶场 · DEBATE

反向角度：有人说「软件实施本来就要现场对细节，进场了还锁范围是不信任，伤感情。小改不算变更，不顺便做就会丢掉科主任的支持；清单后补也一样，先把活干起来才像合作」——你何时承认他们说对了？什么场景必须硬刚书面范围令？请用你真实被「人都来了顺便做、细节现场再商量、做完了对方说本来就该有、你无法另开单价」套住的一单说明：当时若有范围条写清了含/不含（对得上合同或三绿）、变更另单另价、确认人与日期，哪一句能挡住「当时你们都做了，怎么现在才说不含 / 这只是小改又不是变更」？（引导反驳：关系越好越要走入口人把范围基线写清楚，因为免费加项的责任往往先砸在小李头上再转给你；「先做清单后补」会做成对你不利的范围，而且是你在垫工时。）

靶向（行业深挖）：进场后范围锁定的最小条件该是什么？选一边并举例：A) 进场令里写了「先做哪一段」就可以边做边补细节，清单后补；B) 和科主任口头对一下、群里确认一句即可，小改不算变更；C) 必须有双方书面确认的含/不含清单（对得上合同或三绿）+「变更另单另价」原句 + 确认人与日期。用 LIS 或输血标准档举一例：小李只回「人都来了，顺便把危急值也做了，这都是系统该有的」时，你怎么用范围条挡、又不显得在指挥检验科、也不自己起草「我方理解原合同已包含某某功能」群发？若先发输血线，如何避免把「迎检通过」写进含项、变更条件或收款开关？请回聊天里辩；空泛表态不算回靶。

开拓风暴 · STORM · 周二仅跨界钩子（非完整 A/B/C）

病理科·冰冻切片术中送出—报告回收超时看板

手术还在台上，标本送到病理，要在约定时限内把冰冻报告收回手术室，才能决定切缘和术式。现在多靠电话催和纸质登记，台次一密，对不上「何时送出、何时收报告、谁在等、是否已经超时」。小厂+AI 可做送出/回收打点、超时预警和未收回清单，但不碰病理诊断结论，不碰 LIS 核心报告，不碰发血决策，不抢主线回款。这一刀不是昨天的体检阳性复查召回，不是灭菌包发放—回收，也不是标本不合格、标本转运、微生物阳性预警或报告时效投诉——只盯术中冰冻已经送出、报告还没回到台上、时限即将被突破的那一段。冲富直觉：每家有术中冰冻的医院都为台上等待着急，可沿已有院内部署旁路加购，或做成轻量台账复制到多院病理与手术室之间。陷阱：被拉去替代整套病理系统 / 保证冰冻准时不出错，或被当成自动诊断——时限记错会砸到手术安全桌上，必须人审出门，禁止宣称「保证冰冻零超时 / 替代病理医生出报告」。也别抽走补范围条与作战纸的时间。今日不展开 A/B/C——主线仍是交首发包（若还没有）+回执条+传阅条+上会条+纪要条+进场条+范围条。先过范围闸，再想跨界。
