今天仍无可批作业。上周五「出门证三绿」催下班前最小包，周末纸仍空。七格全红灯空：①L1结果包 ②L2决策链 ③L3三档菜单 ④L4止损/让步 ⑤L5里程碑+人情 ⑥一页上场版 ⑦证据包P1～P4。今日课题不是重开 DoD / 黄灯 / 黄转绿细则，而是给三绿最小包加一把「首发闸」——今天必须离厂交卷。第1周须闭环；今天禁止硬开第2周。

社论导读 · EDITORIAL

上周五把出门证拍在桌上：至少三格绿灯可进合同句，其余黄灯占位，一页上场版标题齐，证据包至少 P1 或 P2 黄灯以上。周末过去，纸还是空的。周一上午小李不会问你规则背了几条，他会说：「周末不是说材料周一补吗？你还在写啊，先口头报个大概让我转。」这句话听起来像体谅，实际是在替你完成一次被改写的首发：他转给院长的「大概数」会变成院内默认口径。

「材料在写」写在你电脑里，对小李、老张、院长等于零。咨询公司有 First External Artifact（首份对外可读物），企业软件有 preview SOW freeze：第一份能被客户转发的制品必须过 Ship Gate（发运闸）。今天不重开已讲过的定位细则，只加一把闸：三绿最小包今天交到聊天或邮件附图。首发不是七绿完美；首发是对外可转发最小包第一次离厂。

「首发＝三绿最小包离厂；没首发，就别假装『材料在写』。」

— 亿万富翁导师 · 本周金句

今日课题 · BRIEF

首发仪式（First Publish Gate）——三绿最小包今天必须出门。为 LIS 或输血标准档至少一线交「首发包」：①点名哪三格绿；②三句绿灯可进合同句正文（不是标题）；③一页上场版正七+背三标题齐；④证据包至少 P1 或 P2 黄灯以上。其余格至少黄灯占位；禁止整页空白；写「差不多」＝未达。输血纸勿把「迎检通过」当收款开关；勿编假财报、勿抄示例。交了红笔批；没交则 homework 继续 pending，第2周继续锁。角色照旧：信息科小李、主任老张、设备科小王。

优先三绿建议仍是 L1+L3+L5（自选须点名）。没在周五点名的，今天点名再写正文——点名本身不是首发，正文离厂才是。

拷问：小李说「还在写啊，先口头报个大概让我转」——你递出可转发首发包，还是用「还在完善出门证」掩护口头大概数？

轻量硬理论 · Ship Gate / First External Artifact

Ship Gate＝事先约定的「第一份对外可读物可以离厂」检查清单。First External Artifact＝对方第一次拿到、并能转发给第三人的文本。四条：①厂内草稿≠对外制品，进度靠「对方已经能转发」证明，不靠「我还在写」；②第一次离厂定口径——小李若用口头大概数去转，那才是被改写过的真首发；③首发≠七绿完美，允许带待补清单，不允许空白或「差不多」；④Preview SOW freeze：第一份可转发范围说明冻结，后面改走变更单。十来人厂没有售前军团擦屁股——你更需要首发闸。第2周大理论等首发包交上来后再开。

世界500强 / 顶级售前 · 可偷的纪律

咨询公司把「第一份客户可读物出门」当项目纪律：内部红灯没灭，文件不许进客户转发链。企业软件售前有 deal desk / proposal gate：第一份可被转发的 preview SOW 必须范围可指、验收可勾、不含可见。医疗信息化更碎：小李一催「上面要材料」，你若没有首发包，他只能用口头大概数去转——那份转述会成为院长会上的「供应商说过」。首发是给对方院内对齐用的，不是给你面子用的——今天交三绿最小包，是帮对方少开一次丢人返工会，也是阻止别人替你写第一版口径。

亿万富翁致富经

小老板怕首发，觉得纸还没完美、先口头应付晚上再补。富老板把首发当廉价保险：交卷成本是今天写出三句绿句正文并附图离厂；不首发成本是小李用他自己的大概数替你首发，范围、价锚、触发被别人的转述钉死。你本人就是标准档口径的唯一作者。纸可以黄，首发不能缺。致富算术：首发闸暴露「还在写」→今天交三绿最小包→对外不裸体；跳过首发→口头大概数出门→人情与砍价替你填空。

行业落地 · 首发包四件套（今天离厂）

角色照旧：信息科小李、主任老张、设备科小王。按真实院况填；比例勿编假财报。

① 点名三绿

今日最低：写明哪三格绿（建议 L1+L3+L5，自选须点名）。不说哪三格或「都差不多」＝未达。

② 三句绿灯正文

今日最低：三句可进合同句全文，陌生人读得懂边界/含不含或价锚/触发。只有标题或口头大概＝未达。

③ 一页上场版

今日最低：正七块+背三刀标题齐（内容可黄）。只有聊天记录或标题缺块＝未达。

④ 证据包 + 其余格

今日最低：P1（演示路径）或 P2（验收勾选）黄灯以上；其余格标题+待补一句。口头「做过几家」或整页空白＝未达。

判定：四件套齐+其余格黄灯占位→今天算首发，允许小李转发对齐（待补须可见）；缺任一件、空白或「差不多」→厂内收口，禁止口头甩大概数。LIS 或输血至少一线；半成品可以黄，不能零绿装「材料在写」。

虚拟院：小李周一上午催「先口头大概让我转」——口袋空则口头数进院长桌，小李穿帮，老张把现场现编当承诺，小王砍标价且不认口头触发。掏出首发包：「三绿已点名，三句绿灯正文在此，上场版标题齐，P1/P2 挂后；其余黄灯待补贴页脚。您直接转发，口头大概数我怕给您对院长口径添乱。」首发挡口头改写；没首发只能赌关系。输血绿句可写合规闭环怎么验收，不可把「迎检通过」写成收款开关。

厚黑人情 · 老油条 · HOUHEI

对方催「还在写啊，先口头报个大概让我转」

本课角度：绑首发仪式 / First Publish Gate / 三绿最小包离厂。周一上午小李说「周末不是说材料周一补吗？你还在写啊，先口头报个大概让我转」——牌底是让你在可转发文本出门前，先交出可被他转述的口头数。合法可试。禁止行贿、回扣、假票、围标。

一句招 · 一句戒

招：「李哥，周末说周一补，我今天把三绿最小包首发给您——三句可进合同的绿句您直接转院长对齐口径，一页上场版标题齐、证据也挂上，其余黄灯待补写在页脚。这样您不用靠口头大概数对院长，省得会上被追问再开一次返工会。」把首发包译成帮对方省返工、对院长有口径。

戒：永远不要用「还在完善出门证」掩护口头大概数或空白答应——那等于把首发权交给对方的转述；可以承诺「今天把可转发最小包发给您」，不能一边说材料在写，一边点头让他先转大概数。

讨论靶场 · DEBATE

反向角度：有人说「首发仪式是形式主义，材料还在写就先口头报个大概让小李转，晚上再补纸也一样」——你何时同意、何时硬刚「没首发，就别假装材料在写」？用真实被「周一补材料、先口头大概」套住的一单说明：当时若当天交了可转发首发包，哪三句能挡住院长追问？（引导：晚上补的纸追不上上午已经被转述的口径。）

靶向（行业深挖）：首发该以什么形态「离厂」？A) 聊天里贴三句绿句正文+一页上场版截图；B) 邮件附图/PDF，正文里点名三绿；C) 只口头念给小李听，让他自己整理再转。用 LIS 或输血举一例：今天上午小李说「别发文件，你口述我自己整理转院长」——你如何既完成首发（材料离厂有据、口径是你写的），又不让小李替你改边界？若先发输血线，如何避免把「迎检通过」写进首发绿句当收款开关？

开拓风暴 · STORM · 周一完整 A/B/C

县域医共体·标本转运时效异常周报一键出门

采集→交接→签收的时效与超时异常清单。乡镇采样点送到牵头院，路上耗时靠口头扯皮、周报靠人工翻交接本。AI 吃时间戳初筛与周报草稿；更值钱：节点定义、授权、审计、谁付费、人审边界。不碰 LIS 核心报告结论，不碰发血决策，不抢主线回款。这一刀不是县域报告时效、外送回传对账，也不是交叉配血时效 SLA——只盯标本还在路上的那一段。

路径 A · LIS 旁路「转运时效异常周报导出」

起步：现有 LIS 复用条码/接收时间戳，加超时清单+周报导出。赚钱：院/医共体年费或按次。冲富：中（复用部署可复制，票面多为加购）。陷阱：被拉去全链条 TAT 大屏；节点定义扯皮——写进含/不含，付款走里程碑，不绑「全县转运达标」。与主线：可接加购；勿抢回款。

路径 B · 轻 SaaS：采集/交接/签收扫码（不碰 LIS 核心）

起步：采样点、司机、中心各扫一次码，输出时效看板与异常周报；不写入 LIS 报告、不碰发血。赚钱：订阅+超量网点包。冲富：中高（不全靠单院招标）。陷阱：被当成官方质控认证；隐私与轨迹翻车——须授权书/审计/免责；无权限模型别规模化。与主线：分队；勿抢回款。

路径 C · AI 读交接本/微信照片/Excel 生成异常周报草稿（更野）

起步：AI 批量读交接本照片、微信群报数、Excel 台账，出「本周超时点位+疑似原因」草稿，人审出门。赚钱：项目制+抽检费或与A/B捆绑。冲富：高（附高风险）。陷阱：幻觉错怪网点、时间戳读错、被当成自动问责；禁止宣称「AI已认定责任」。与主线：严格分队；主线未回款勿抽核心实施清照片。

选边：90 天只押 A/B/C 哪条？回聊天；写首笔收款触发证据一句；若会抽走补首发包时间——先交首发包，再开风暴。AI 可起草绿句与周报目录，定稿前须你本人删掉「保证迎检通过 / AI已认定责任 / 保证全县转运达标」。
