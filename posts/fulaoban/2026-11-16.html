作业回看 · HOMEWORK CHECK

今天仍无可批作业。上一堂落地的课是上周三「传阅闸门」，周四、周五两跑未落地，纸仍空（即便你今天一并交出首发包、回执条和传阅条，也还没有会名、日期、议题原句和宣读人）。七格全红灯空：①L1结果包 ②L2决策链 ③L3三档菜单 ④L4止损/让步 ⑤L5里程碑+人情 ⑥一页上场版 ⑦证据包P1～P4。今日课题不是重开传阅细则 / 回执闸门 / 首发仪式 / 出门证三绿，而是给传阅加一把「上会闸」——已阅不等于已上会。没首发就谈不上回执，没回执就谈不上传阅，没传阅就谈不上会。第1周须闭环；今天禁止硬开第2周。

社论导读 · EDITORIAL

上周三把传阅闸拍在桌上：一人回执不等于决策链已阅，要第二人书面已阅三句绿句。「回头说说」「已经转了，你等消息」「内部同步」不算传阅。今天是周一。中间那两天例行没能落地，课序不补开新题目，直接往前加一把闸。即便你已经要到了老张的已阅（更多人连首发包都还没交），下一个自我安慰会准时上门：「他们都看过了，等开会再说；先内部酝酿一下；我会在会上提一嘴；已经帮你排上了，你等通知。」

周一上午几乎是标准剧本。小李不会主动把三句绿句写成设备委员会或院长办公会的正式议题。他会回：「这事等下次开会再说，具体哪天院办还没定。」或者：「不用单独占议题，我提一嘴就行。」再防你一步：「已经排上了，你等通知吧。」这句话听起来像院内程序已经启动，实际是在用「口头承诺会提」冒充正式上会。牌面是材料进了决策链；牌底是院长会上院办可以说「这期议程没有这一条」，老张可以说「这不在今天的议题里，下次再议」——你口袋里只有小李一句「我会提一嘴」。

有人会自我安慰：「都传阅了就别再催排期，上会是院内的事，你催议程显得像供应商在推动院办。」咨询与企业软件售前有一条纪律叫 Agenda Gate / Decision Forum Scheduling（上会闸 / 决策会排期），还有 Calendar Commitment（日历承诺）：干系人看过了范围句，不等于医院已经为这三句留出了正式决策时段。你要偷的不是会议管理系统，而是纪律：

「已阅 ≠ 已上会；没有会名、日期、议题原句和宣读人，就别假装『已经在走院内程序』。」

— 亿万富翁导师 · 本周金句

今日课题 · BRIEF

上会闸门（Agenda Gate）——决策链已阅之后，要书面排上正式会议：会名 + 日期 + 议题原句 + 谁宣读

为 LIS 标准档或输血标准档至少一线：
1. 若仍无首发包：今天仍须先交「三绿最小包首发」。没首发就谈不上回执，更谈不上传阅和上会。
2. 若仍无回执：补回执条，对方书面点名至少两句绿句；禁止「嗯 / 收到了 / 回头再对」。
3. 若仍无传阅：补传阅条，不能只传给小李，除小李外至少一人书面已阅；禁止「回头说说 / 已经转了你等消息」。
4. 再交「上会条」五格：①会名（真实决策会全称，禁止「等开会」）；②日期（具体到日，「近期 / 下次 / 等院办通知」不算）；③议题原句（不能是「LIS事宜 / 输血升级聊聊」空筐，须含或附三句绿句并由宣读人当场读出）；④呈报 / 宣读人具名（禁止「到时候看谁在」）；⑤有权写入议程的人留下可转发确认。
5. 禁止把「等开会再说 / 先内部酝酿 / 我提一嘴 / 已经排上了你等通知」（无日期无议题原句）当成已上会。路由仍走小李，不私戳院办抢议题。24 小时仍无日期则提醒一次；48 小时仍停在「等开会 / 提一嘴」则交「已阅未上会」记录。
6. LIS 或输血至少一线；输血勿把迎检当收款开关；勿编假财报、勿抄示例。
7. 交了红笔批；没交 → homework 继续 pending，第2周继续锁。

拷问：小李回「等开会再说，院办还没定日子」「我提一嘴就行」或「已经排上了，你等通知」——你把它当「已经在走院内程序」收下，还是请他写出会名、日期、议题原句和宣读人？

商学院硬理论 · Agenda Gate / Decision Forum Scheduling

Agenda Gate（上会闸）= 事先约定的「范围句必须作为具名议题，出现在一次有日期的决策会上，并由指定的人宣读」的检查清单。Decision Forum Scheduling = 文件不靠冠军用户口头「提一嘴」，而靠可指认的会名、议程条目和宣读人进入决策时段。Calendar Commitment 说得更硬：没写进日历的会议，只是愿望。它不是逼你指挥院办，是反自我欺骗：

1. 已阅 ≠ 已上会：老张点名已阅，只证明专业这条线看过纸。进度靠「某次会的议程上出现了可宣读的议题原句」证明，不靠「他答应提一嘴」。
2. 「提一嘴」≠ 正式议题：决策会对齐必须落到编号议题和会前预读，不能用「我会顺便说」代替。你厂没有客户成功团队替你会后圆。
3. 决策过程不只是谁拍板，还包括在哪次会上拍：MEDDPICC 的 Decision Process 问的是论坛、日期、材料和呈报人。
4. 上会是变更的前置：后面改边界、动触发、砍档，走的是「正式议题被讨论之后的变更」，不是「这事我们从没正式议过，所以可以从头谈」。

类比（点名思路，勿堆假财报）：咨询顾问上指导委员会前，要把 SOW 写成编号预读并确认它是议程上的一条；企业软件销售对资本委员会之前，不能只拿冠军用户一句「我会提一嘴」去对 CFO。十来人厂没有售前军团——你更需要上会闸，因为小李一句「等开会再说」，这个会可以拖过整个季度，三句绿句停在「大家都看过了」的抽屉里。第2周大理论等首发包、回执、传阅和上会交上来、第1周闭环后再开。

世界500强 / 顶级售前实战（可偷的纪律）

像样的咨询公司把「预读材料必须成为决策会的编号议题」当成纪律：SOW 只有acknowledge，项目经理不许对外说「下一次指导委员会就会定」。像样的企业软件售前有 capital committee / steering committee agenda check：条目没写进即将出席的那次会议程之前，销售被禁止说「已经在走正式程序」。医疗信息化场子更碎：小李一回「等开会再说 / 我提一嘴就行 / 已经排上了你等通知」，你若没有上会条，院办可以说「这期没有这条」，老张可以说「今天排满了，下次再议」——你只有一句「小李说他会提」。

再偷一条：上会是给小李减责用的，不是你在推动院办、也不是你在越级。 小李怕院长临时点名问那三句，议程上却没有条目，他只能临场编档位和付款节点；老张怕已经书面已阅，会上却没有正式议题；院办怕非正式话题冲进会议。你要做的，是给小李一份可以呈报的议题原句——三句绿句写在条目里或附件里，会上他只需宣读，不必替你即兴答辩。

亿万富翁致富经

钱藏在正式时段里，不藏在「大家都看过了」里。十来人厂最容易死在一句「等开会再说」：纸可以是绿的，传阅可以是齐的，然后在抽屉里躺过一个季度，因为从来没有变成议程上的一条。富人卖的是有日期的决策论坛，不是进度幻觉。你今天若只得意于「老张已经阅了」，没有会名和日期，你就还在给医院做免费咨询——而且这咨询连上场的门票都没有。

行业落地 · 上会条（今天出门）

格 最低达标 未达（禁止当上会）
会名 真实决策会全称（院长办公会 / 设备委员会 / 信息化领导小组，或院内对应会） 「等开会」「内部会」「他们自己会」
日期 具体到日，可写「本周三院办会（11/19）」 「近期」「下次」「等院办通知」无日期
议题原句 含或附三句绿句，宣读人能当场读出 「LIS 事宜」「输血升级聊聊」空筐
呈报 / 宣读人 具名（小李或老张） 「到时候看谁在」「到会再说」
排期确认 有权写入议程的人留下可转发痕迹 「已经排上了，你等通知」无截图、无原句

判定：有首发包+有回执+有传阅（第二人已阅）+五格齐→今天算过上会闸；只有「他们都看过了」或「我会提一嘴」→禁止把口头承诺当成已经在走院内程序。

虚拟院：小李周一上午回「等开会再说 / 我提一嘴就行 / 已经排上了，你等通知」——你若把这句当上会，下周院长办公会结束，院办说「这期议程没有 LIS 这一条」，老张说「今天议题排满了」，压力转成你再等下一次。掏出上会条：「李哥，会上我听您的，我不直接找院办抢议题。请按这五格写一会名、一个日期、一条能宣读三句绿句的议题原句，并请有权排期的人点一下确认。这样会上不是靠您临场提一嘴，而是有正式条目可念。」上会挡「提一嘴」；没上会只能赌下一次会还记不记得你。上会走小李路由，不私下绕过他去戳院办。输血绿句可写合规闭环怎么验收，不可把「迎检通过」写成收款开关，也不可写进议题原句当触发。

议题原句示例（可改写，勿原文抄成作业）：LIS「请审议 LIS 标准档结果包（附件三绿）：范围按第 1 句验收，档位按第 2 句锁定，付款触发按第 3 句执行。呈报人：信息科小李。」输血「请审议输血标准档结果包（附件三绿）：闭环验收按第 1 句，档位按第 2 句，里程碑付款按第 3 句；不含以迎检通过为收款条件。呈报人：输血科主任老张。」

厚黑人情 · 老油条 · HOUHEI

对方回「等开会再说」「先内部酝酿一下」「我会提一嘴」或「已经排上了，你等通知」

本课角度：绑上会闸门 / Agenda Gate / 已阅不等于已上会。小李说「等开会再说 / 先内部酝酿 / 我提一嘴 / 已经排上了你等通知」——牌底是用口头承诺代替正式议题。合法可试。禁止行贿、回扣、假票、围标。

一句招 · 一句戒

招：把「请帮我排上设备委员会 / 院长办公会」译成「帮小李省院长会上没正式议题却被临时点名、一个人挨问」——提前占一个写了三句绿句的正式议题，会上他只需宣读档位和付款节点，不必临场编。你不是在推动院办，是在给入口人准备可念的条目，让他少在院长面前露白。

戒：不要把「等开会再说 / 先内部酝酿 / 我提一嘴 / 已经排上了你等通知」当成已上会。没有会名、日期、议题原句和宣读人，就是还没过闸。也不要绕过小李私戳院办抢议题——那是砸他的院内面子，把入口人变成对手。可以温柔、可以让他选哪一次会、由谁宣读，不能一边说已经在走程序，一边接受一句「你等通知」。

可立刻试：写上会条时把这句抄在页脚。上午若真有人回「等开会再说」或「我提一嘴就行」，直接用：「李哥，会上怎么呈报听您的，我不直接找院办。为了避免院长临时点名、您一个人挨问，请帮我占一条正式议题：会名、日期、议题原句（附件就是那三句绿句）、由您或老张宣读。您把这五格点一下，我按您的口径准备一页纸。」关系越好越要走他做路由。催的不是「快点开会」，是「别让他在没有条目的会上被问到三句却答不上」。

讨论靶场 · DEBATE

反向角度：有人说「都传阅了就别再催排期，上会是院内的事，你催议程显得像供应商在推动院办，伤感情；他提一嘴和正式议题效果一样」——你何时承认他们说对了？什么场景必须硬刚书面排期？请用你真实被「说会提一嘴、两三个月后议题里还没有」套住的一单说明：当时若有上会条写清了会名、日期、议题原句和宣读人，哪一句能挡住「这期没有这条 / 今天排满了下次再议」？（引导：关系越好越要走入口人把条目送进议程，会后改口的代价往往先砸在小李头上；「提一嘴」会提成对你不利的版本，或根本没提。）

靶向（行业深挖）：议题原句最小该写成什么样？选一边并举例：A) 「LIS 升级事宜 / 输血系统建设」这种空筐就够，会上再展开；B) 有会名 + 日期即可，议题可含糊；C) 必须含或附三句绿句，并点名宣读人。用 LIS 或输血标准档举一例：小李只回「已经排上了，你等通知」而院办会上说「这期没有这条」时，你怎么用上会条挡、又不显得在指挥院办？若先发输血线，如何避免把「迎检通过」写进议题原句 / 绿句当收款开关？请回聊天里辩；空泛表态不算回靶。

开拓风暴 · STORM · 周一完整 A/B/C

标本不合格闭环（溶血 / 量不足 / 容器错误）· 护士端重采通知 + 原因周报

标本已经送到实验室、因质量不合格被拒收之后，把「谁在何时因何原因拒收、护士是否收到重采通知、何时重采送达」留下闭环，并按病区 / 原因出周报。溶血、量不足、容器用错、条码贴错，是检验科和护理部之间最常见的扯皮：电话打过但没记录、夜班换人后重采单失踪、月底对账各执一词。不碰 LIS 核心报告结论，不碰发血决策，不抢主线回款。这一刀不是危急值闭环、报告时效、外送回传对账、交叉配血时效 SLA、标本转运时效，也不是上周的微生物培养阳性分级预警——那些都发生在结果已出或标本还在路上。它只盯标本已经到实验室、因质量被拒、重采通知还在路上、原因对不上的那一段。AI 吃拒收原因初分类、护士端通知话术与病区周报草稿；更值钱：拒收规则由谁签、渠道授权、重采时限谁认、谁付费、人审边界。

路径 A · LIS 旁路「不合格编码 + 护士通知 + 原因周报导出」

起步：现有 LIS 复用标本登记与不合格登记，加原因编码、护士端 / 病区通知记录、重采计时、未闭环清单、周报导出。赚钱：院年费或模块加购。冲富：中（复用部署可复制，票面多为加购）。陷阱：被拉去全院护理消息中台或替代护理不良事件系统；拒收规则扯皮——写进含/不含，付款走里程碑，不绑「不合格零漏通知」或「替代护士判断采血是否合格」。与主线：可接加购；勿抢回款。

路径 B · 轻 SaaS：拒收通知与原因台账（不写入 LIS 报告）

起步：检验科录入或只读接口接入不合格条目，向病区护士推送重采通知，记录已读 / 未读与重采回传，输出原因台账与周报；不写入 LIS 报告、不碰发血。赚钱：订阅+超量病区包。冲富：中高（不全靠单院招标）。陷阱：被当成官方必达通知认证或漏通知自动问责护理；隐私与护士手机号翻车——须授权书/审计/免责；无权限模型别规模化。与主线：分队；勿抢回款。
