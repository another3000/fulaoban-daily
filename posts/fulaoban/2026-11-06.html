今日课题 · BRIEF

出门证三绿（Weekend Exit Pass / Three-Greens Gate）——把本周 DoD + 黄灯仪式 + 黄转绿闸门收成「下班前出门证」。七格不许全红；至少 三格写到绿灯可进合同句（优先建议 L1 结果包、L3 标准档含/不含、L5 里程碑触发；也可自选三格但须点名）；其余格至少黄灯占位（标题 + 待补一句）；一页上场版正七 + 背三标题必须齐；证据包至少 P1 或 P2 黄灯以上。目标：周末微信局到来前，口袋里有「三句绿灯可转发院长」的最小包。

判定：①七格每格必须标绿灯可进合同句 / 黄灯待补 / 红灯空——禁止整页空白；②至少三格达「可进合同句」（陌生人读得懂边界；对齐本周黄转绿四条规则；写「差不多」＝未达）；③正七+背三标题齐；④证据包至少 P1 或 P2 黄灯以上；⑤输血纸不可把「迎检通过」写成收款开关；勿编假财报、勿抄示例当作业。

行业落地 · 小李周末要材料转发院长

虚拟院照旧：信息科小李、检验科/输血科主任老张、设备科小王。周五傍晚小李微信：「老板催，你把标准档材料发我，我转院长——先口头定了，细节周一补。」

零绿口袋：转发的是「大概含危急值 / 上线后付 / 差不多这个价」。院长一追问，小李穿帮，压力转回你；老张会上把黄灯句当承诺；小王砍价时你没有可指触发，第一刀砍标价。

三绿口袋：三句可进合同句（例如 L1 三条可验收结果+两条不含；L3 标准档含/不含各≥2 且价锚诚实；L5 四节点+触发证据文件名/签字角色）+ 一页上场版标题齐 + P1 或 P2 黄灯以上。回小李：「李哥，这三句绿灯您先转院长对齐边界；其余格黄灯待补清单贴页脚，绿灯补齐版周一邮箱——口头先进场我怕给您添乱。」小李有可转发最小包，老张能指不含，小王要砍也得先对触发证据。

纪律：出门证不是「七格全绿才许说话」——那是完美主义拖延；也不是「黄灯也能假装能报」——那是把穿帮风险写进院长桌。出门证＝至少三绿；没有三绿，不许假装『差不多能报』。

厚黑人情 · 老油条

绑「出门证三绿」。周五不教新话术长段，只给一句招 + 一句戒。合法、可立刻试；禁止行贿、回扣、虚假发票、围标串标。对方周末说「先口头定了，材料周一补」——越是催转发，越要把「三句绿灯可进合同句」当院内可转发最小包递出去，用三绿换对齐时间，不换口头承诺。

一句招：「李哥，我这有三句绿灯（结果边界 / 标准档含不含 / 里程碑触发——按你点名的三格），您先转院长对齐；其余黄灯待补周一邮箱补齐——口头先进场我怕给您在院长桌上穿帮。」用「三绿最小包帮你转发」代替「我拒绝表态」。

一句戒：永远不要拿「还在写黄灯」当空白口头答应的借口——黄灯可以占位，但不能用「我还在写」去掩护一句没有边界的口头承诺；没有三绿，就别假装差不多能报。
