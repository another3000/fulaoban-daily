进场闸门：有纪要不等于可以进场开工

2026.11.23

周一 · 上海

对照计划 · 第1个月第1周 · 定位与报价 · 课次21 · 催交进场闸门 · 不硬开第2周

作业回看 · HOMEWORK CHECK

今天仍无可批作业。上一堂落地的课是上周二的「纪要闸门」，上周三到周五例行未落地（含周五作业体检），纸仍空（即便你今天一并交出首发包、回执条、传阅条、上会条和纪要条，也还没有合同原句、首款证据和进场授权）。七格全红灯空：①L1结果包 ②L2决策链 ③L3三档菜单 ④L4止损/让步 ⑤L5里程碑+人情 ⑥一页上场版 ⑦证据包P1～P4。今日课题不是重开纪要细则 / 上会闸门 / 传阅闸门 / 回执闸门 / 首发仪式 / 出门证三绿，而是给纪要加一把「进场闸」——有纪要不等于可以进场开工。没首发就谈不上回执，没回执就谈不上传阅，没传阅就谈不上会，没上会就谈不上纪要，没纪要更谈不上进场。合同还没盖章、首款还没影子，也要先交预置版进场条件清单，而且今天不派人。第1周须闭环；今天禁止硬开第2周。

社论导读 · EDITORIAL

上周二把纪要闸拍在桌上：没有纪要原句、决议性质和会后责任人期限，就别假装「会上已经定了」，更别按口头表态开工。「原则上同意」「先做起来，纪要还没出来」「我口头跟你同步」不算决议。今天是周一。中间空了三个工作日（例行未落地），自我安慰却不会停。即便你已经要到了纪要（更多人连首发包都还没交），下一个请求会准时上门：「纪要都写了，院长也点头了，你先派人来；合同章设备科还在走；预付财务在走，你先把测试环境搭起来；先派人来体现诚意，不然预算可能被砍；边做边签，大家都是老关系。」

周一上午几乎是标准剧本。小李转发一页纪要（或者只转述「已经写进去了」），接着说：「你们先派两个人来接 LIS 测试环境、跟检验科对接口，采购文件法制还在审，首款这个月指标紧、下月初肯定能批。」老张补一句：「你先把标本流程跑通，我们好在科务会上说已经启动了。」小王再防你一步：「内部流程慢你别计较，人先占上，别让明年预算被挤掉。」这句话听起来像项目已经启动，实际是在用「纪要 / 诚意 / 流程还在走」冒充进场授权。牌面是会上定了、纪要有了；牌底是人进去以后，范围会被做成对你不利的版本，首款可以再拖一个季度，合同可以把三句绿句改掉——你口袋里只有一页纪要，甚至已经开始垫差旅和工时。

有人会自我安慰：「医院流程本来就慢，纪要都有了还卡合同和预付是不信任，伤感情；小厂不先做就没机会；先调研、先搭环境不算正式开工。」咨询与企业软件交付有一条铁纪律叫 Kickoff Gate / Mobilization Gate（进场闸 / 动员闸），还有更硬的 No PO, No Work（没有采购订单，就不派工）：会议纪要是院内决策痕迹，不是对你的商业授权。你要偷的不是对方的章，而是纪律：

「已入纪要 ≠ 可以进场；没有含三绿的合同（或等值采购文件）、首款证据和书面进场授权，就别派人，更别把『先调研 / 先搭环境』当成不算开工。」

— 亿万富翁导师 · 本周金句

今日课题 · BRIEF

进场闸门（Kickoff Gate / Mobilization Gate / No-PO-No-Work）——纪要形成之后，要书面进场令：合同原句（含或附三绿）+ 首款证据 + 进场范围、日期与授权人

为 LIS 标准档或输血标准档至少一线：
1. 若仍无首发包：今天仍须先交「三绿最小包首发」。没首发就谈不上回执，更谈不上传阅、上会、纪要和进场。
2. 若仍无回执：补回执条，对方书面点名至少两句绿句；禁止「嗯 / 收到了 / 回头再对」。
3. 若仍无传阅：补传阅条，不能只传给小李，除小李外至少一人书面已阅；禁止「回头说说 / 已经转了你等消息」。
4. 若仍无上会：补上会条五格；禁止「等开会再说 / 我提一嘴 / 已经排上了你等通知」。
5. 若仍无纪要：补纪要条五格（会名日期、原句含或附三绿、决议性质、会后责任人期限、可转发摘录）；会尚未开先交预置版纪要条；禁止「原则上同意 / 先做起来 / 我口头跟你同步」。
6. 再交「进场条」五格：①合同或等值采购文件（名称 + 编号 + 签署或盖章日期；须含或附三句绿句。已盖章合同、PO、正式中标通知可算；「合同草稿 / 我们内部已经批了 / 章在路上」不算）；②首款状态：到账证据（金额 + 日期）或请款已受理的书面回执（责任人具名 + 承诺到日）。「财务在走 / 下个月肯定能批 / 指标有了就等付款」不算；③进场范围与日期（必须对得上合同或绿句，禁止「先来看看 / 先把测试环境搭了」这种空筐）；④进场授权人（具名：谁书面同意你们进场）；⑤可转发文本（合同关键页 / PO / 进场通知；「口头叫你先来」不算）。
7. 禁止把「纪要都写了你先派人来 / 合同章还没盖先做起来 / 预付财务在走你先开工 / 先派人体现诚意 / 边做边签 / 先调研、先搭环境不算正式开工」当成进场令。合同尚未盖章、首款尚无证据：今天交预置版进场条件清单，不派人。若已经有人在现场：补交进场条；48 小时仍停在「章在走 / 财务在走」则交「已进场无合同或无首款」记录，并按 L5 逾期动作执行（能停则停新增范围，不再靠人情加功能）。
8. 路由仍走小李，不绕过入口人去催财务或法制。LIS 或输血至少一线；输血勿把「迎检通过」写成进场条件或收款开关；勿编假财报、勿抄示例。
9. 交了红笔批；没交 → homework 继续 pending，第2周继续锁。L1～L5 + 一页上场版 + 证据包继续催交。

拷问：小李回「纪要都出来了，你先派人来，合同章还在走，预付财务在走」——你把它当进场令收下并派工，还是请他写清合同原句、首款证据和进场授权？

商学院硬理论 · Kickoff Gate / No PO, No Work

Kickoff Gate（进场闸）= 事先约定的检查清单：「会议形成决议之后，必须再拿到商业授权，才能动员实施团队」。Mobilization Gate（动员闸）强调的是同一件事的执行面：差旅、进场人员、测试环境账号、接口联调，都属于动员，不是「随便先看看」。No PO, No Work = 没有采购订单（或等值的已签署合同 / SOW），就不发生可计费或不可计费的现场工作。工程和系统集成里还有独立的 Notice to Proceed（开工令）：合同签了，也不等于当天可以进场，还要一纸书面开工。

这里要把三件事拆开，不能缩成一句「纪要都有了你先来」：
• Decision Record（决议记录 / 纪要） 回答：院内对范围句的态度是什么？
• Commercial Authorization（商业授权） 回答：谁用哪笔预算、按哪个验收和付款节点买？证据是含三绿的合同或等值 PO，加上首款到账或请款已被受理的书面回执。
• Mobilization（进场动员） 回答：哪一天、哪些人、做合同里的哪一段？证据是书面进场范围、日期和授权人。

把决议记录直接当成商业授权，再把商业授权省略成「先来体现诚意」，咨询公司管这叫「免费发现阶段」或「善意进场」——听起来像关系，算出来是垫资。更糟的是范围解释权会跑到已经进场的那一边：你做过的，很难再收进菜单「不含」；你没做过的，对方会说「你们人都来了，怎么还没有」。L3 的边界和 L5 的预付纪律，会在现场被人情一口一口吃掉。

世界500强 / 顶级售前实战（可偷的纪律）

Accenture、IBM GBS、Deloitte 咨询条线，普遍把 No PO, No Work 写成交付政策，不是销售口号。指导委员会点头、会议纪要写「原则同意启动」，不够让项目经理排差旅、排顾问。他们要的是：已签署 SOW 或合同、客户采购订单号，以及（常见的）首期发票安排或资金已占用的书面确认，然后再发开工通知。有团队试过「先做 Blueprint 工作坊，PO 后补」，结果是高价顾问空转两周、PO 迟迟不出、范围在车间里被打开——后来只能把损失记进售前成本，再在内部检讨为什么破了闸。

工程承包更硬。FIDIC 和国内总包惯例里，Minutes of Meeting 从来不是 Notice to Proceed。纪要可以记「同意下周一进场」，真进场仍要业主或监理发书面开工令。软件集成没有监理章，就更容易被一句「先来体现诚意」骗进去。你要偷的不是对方的流程软件，而是这句纪律：纪要归纪要，进场必须另有书面令；令上要有范围、日期和授权人，并且对得上合同里的付款触发。没有 PO、没有首款证据，就没有动员。

亿万富翁致富经

十来人厂最常见的死法，不是报价被当场砍掉，是「纪要写了你先派人」。人一进场，差旅、联调、定制接口全都开始烧；对方却还在「章在法制、款在财务」。三个月后你再要预付，对方会问：人都来了，怎么现在才谈钱？范围也被现场需求撑大，L3 菜单上的「不含」形同废纸，L5 的首款节点变成笑话。纪要是帮小李在院内交差的文件，不是给你的提款单，也不是进场许可证。

关系越好越要过这道闸。老关系最容易说出「边做边签」「先做起来再说」。你给面子先做，就是把谈判筹码留在现场，把现金流风险留给自己。进场闸不是冷淡，是保护双方：小李不用为「谁让供应商没合同、没到首款就进场」挨问，你不用为没有首款的工时和范围改口买单。十来人的厂经不起一次「善意进场」——那不是启动项目，那是把可卖贵、可复制的标准档，做成一单说不清边界的垫资人情。

行业落地 · LIS / 输血 / 十来人厂

继续用固定虚拟院角色演，不换行业：信息科小李、检验科或输血科主任老张、设备科小王。

剧本很常见。纪要条刚有（或小李只是口头说「已经写进去了」），小李微信过来：「纪要都出来了，院长也点头了，你们先派两个人来接 LIS 测试环境、跟检验科对接口。合同设备科还在走章，首款财务说这月预算指标紧，下月初肯定批。先来才显得有诚意。」老张补刀：「你先把标本流程跑通，我们好在科务会上说已经启动了。」小王再加一句：「采购文件法制审核要排期，你们人先占上，别让明年预算被别的项目挤掉。」

你的动作不是翻脸，是走小李路由，出示预置版进场条件清单（就是进场条五格），请他协调：合同或 PO 关键页（含或附三句绿句）、首款到账或请款已受理回执、进场范围与日期、书面授权人。不绕过他去催财务或法制，不自己起草「我方理解即日进场」群发。你可以这样说清利害：「进场日期和先做哪一段听您的，我按合同节点派人；没有这五格，我派人进去，院长要是问谁让供应商没签合同、没到首款就进场，您也不好答。」

若先走输血线：进场范围只写合同里的系统建设、交接和验收条目，不要把「迎检通过」「保障用血安全」写成进场条件或收款开关。迎检是医院的合规责任，不是你厂的到账款开关，更不是派人进场的理由。

今日必做 · DO TODAY

1. 若仍无首发包：今天先交三绿最小包首发。没首发就谈不上回执、传阅、上会、纪要和进场。
2. 若仍无回执：写出回执条，要对方书面点名至少两句；禁止「嗯 / 收到了 / 回头再对」。
3. 若仍无传阅：写出传阅条，走小李路由；除小李外至少一人书面已阅。禁止「回头说说 / 已经转了你等消息」。
4. 若仍无上会：写出上会条五格。禁止「等开会再说 / 我提一嘴 / 已经排上了你等通知」。
5. 若仍无纪要：写出纪要条五格；会未开交预置版。禁止「原则上同意 / 先做起来 / 我口头跟你同步」。
6. 写出「进场条」五格：合同或等值采购文件（含或附三绿）、首款到账或请款已受理书面证据、进场范围与日期、授权人、可转发文本。禁止把「纪要都写了你先派人 / 章还没盖先做 / 财务在走你先开工 / 先派人体现诚意 / 边做边签 / 先调研不算开工」当进场令。合同未盖章或首款无证据：交预置版进场条件清单，今天不派人。已有人在现场则补条，48 小时仍停在「章在走 / 财务在走」则交「已进场无合同或无首款」记录，并按 L5 逾期动作执行。

8. 今日下班前交首发包（若还没有）+ 回执条 + 传阅条 + 上会条 + 纪要条 + 进场条（或预置版条件清单）到聊天或邮件附图。没交 → pending，不进第2周。

厚黑人情 · 老油条

本课角度：绑进场闸门 / Kickoff Gate / 有纪要不等于可以进场。小李说「纪要都写了你先派人 / 章还在走 / 财务在走 / 先来体现诚意 / 边做边签」——牌底是用决策痕迹和人情，代替合同与首款。合法可试。禁止行贿、回扣、假票、围标。

一句招：把「请先出具合同和首款再派人」译成「帮小李省院长事后问『谁让供应商没签合同、没到首款就进场，费用和责任谁担』时对不上口径」——进场条不是你在指挥采购和财务，是给入口人准备可出示的授权痕迹。他只需协调五格，不必在事后一个人扛「是我叫他们先来的」。

一句戒：不要把「纪要都写了 / 合同章还在走 / 财务在走 / 先派人体现诚意 / 先调研、先搭环境不算正式开工」当成进场令。没有含三绿的合同（或等值 PO）、首款证据和书面授权，就是还没过闸。也不要自己先派人再补文件——人一进场，再要预付和守边界，你已经没有谈判筹码。更不要绕过小李直接找财务或分管院长催款催章，那是砸入口人的院内面子，把盟友变成对手。

可立刻试：今天写进场条时，把这句招抄在页脚当备用。上午若真有人回「纪要都写了你先派人」或「财务在走你先开工」，直接用，不靠临场灵感：

「李哥，进场日期和先做哪一段听您的。为了避免院长事后问谁让我们没合同、没到首款就进场，请帮我备齐进场条五格：合同或 PO（含或附那三句绿句）、首款到账或请款已受理的书面回执、进场范围和日期、您或设备科的书面授权。您把这五格点一下，我按节点派人，不在现场把范围做成对您不利的版本。」

关系越好越要走他做路由。催的不是「快点盖章」，是「别让他在没有书面授权的情况下把你的人叫进场」。对方事后若改口「我们没让你们正式开工 / 那只是先看看」，你手里有合同原句、首款证据和授权人，比一句「他叫我先来」硬得多。

讨论靶场 · DEBATE

反向角度：有人说「医院流程本来就慢，这是国情；纪要都有了还卡合同和预付，是不信任，伤感情。小厂不先派人，就没有锁定项目的机会；先调研、先搭测试环境不算正式开工，应该给面子先做」——你何时承认他们说对了？什么场景必须硬刚书面进场令？请用你真实被「先做起来、合同后补、人已经在现场、款迟迟不到、范围被撑大」套住的一单说明：当时若有进场条写清了合同原句（含或附三绿）、首款证据、进场范围日期和授权人，哪一句能挡住「人都来了怎么还谈预付 / 这只是先看看又不是正式开工」？（引导：关系越好越要走入口人把商业授权写清楚，没合同进场的责任往往先砸在小李头上；「先调研不算开工」会做成对你不利的范围，而且是你在垫资。）

体检中心·阳性 / 异常项目复查召回未闭环看板

体检中心的「阳性 / 异常项目复查召回未闭环看板」——体检报告已经出具，其中某些项目阳性或异常，需要通知受检人复查，再追踪是否到检、复查结果是否收回归档。现在多靠检后服务电话加 Excel，换班后对不上「谁通知了、打通没有、约了哪天、来没来、复查报告有没有归档」。单位团检甲方或年审追问时，只能翻通话记录。小厂 + AI 可做「应召回名单 + 联系记录 + 到检状态 + 未闭环周报」，但不碰 LIS 核心报告结论，不碰发血决策，不抢主线回款。这一刀不是危急值闭环，不是微生物培养阳性分级预警，不是报告时效或白话陪诊，不是外送回传、标本不合格闭环、标本转运或交叉配血时效，也不是手术室耗材近效期或灭菌包发放—回收——只盯体检已出异常结论之后、复查召回还在路上、联系与到检对不上的那一段。AI 会吃掉名单草稿、话术和周报；更值钱的是召回规则谁签、通知授权与隐私、人审出门、谁对未闭环负责。

路径 A · LIS / 体检系统旁路「异常标记 + 召回记录 + 未闭环周报导出」

起步：在已部署或在谈的 LIS / 体检系统上，复用已出报告与项目结果，加应召回标记、联系记录、到检日期、未闭环清单、周报导出。赚钱：按院年费或模块加购。冲富可能性：中——复用已有部署与信任，可随项目复制，票面多为加购级。陷阱：被拉去替代整套体检系统或区域检后平台；不绑「保证阳性零漏召」，范围写入菜单，付款走里程碑。可作主线旁路加购；主线未到账时禁止抽核心实施长期伺候这套定制。

路径 B · 轻 SaaS：召回台账与通知（不写入报告结论）

起步：从已出报告导出应召回名单（人工或模板），做通知记录、预约、到检与未闭环看板，不改、不回写报告结论。赚钱：按体检中心或团体检项目订阅。冲富可能性：中偏——可复制到多院和第三方体检，票面更轻，获客要另走。陷阱：被要求做成区域检后中台；通知须先写清授权与隐私，不替代医生解释异常，未接听不得记成已闭环。可与主线并行，但勿用主线回款的人去做多院实施。

路径 C · AI 读体检报告 PDF / 照片生成「应召回名单 + 话术 + 未闭环周报」草稿（更野）

起步：先做人审名单，AI 只出草稿，通知发出必须人工确认。赚钱：按处理份数或项目季费，也可卖给团检甲方检后服务。冲富可能性：中高，但波动大——能减少翻表时间，可跨机构复制；识别错或漏召会砸到投诉与索赔桌上。陷阱：被当成自动诊断；必须人审出门，禁止「AI 保证不漏召」；隐私合规是第一门。只做演示与目录，不抽补进场条和作战纸的时间。

请选一边：A、B 还是 C？先说傍哪一家已有或在谈的体检 / LIS 场景，以及谁付费（医院体检中心，还是组检单位）。先过进场闸，再想跨界——看板替不了今天的进场条和作战纸。用 AI 起草进场条五格提问和召回看板目录都可以；定稿前必须你本人删掉任何「保证迎检通过 / 保证阳性零漏召 / 纪要即授权进场 / 先做起来合同后补」表述，并对照 L1 边界与 L5 预付纪律。
