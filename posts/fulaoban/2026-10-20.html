正式课 THE LESSON

今日课题：为 LIS 与输血各设计一版「三档报价菜单」

基础档 / 标准档 / 旗舰档——写清每档含什么结果、不含什么、价格锚点逻辑（不是功能清单堆砌）。

商学院硬理论

价格锚点（Anchoring）与 Good-Better-Best

行为经济学里，人判断「贵不贵」很少看绝对值，而是看参照系。先听到的数字会钉住后续判断——这就是锚点。B2B 产品化服务常用 Good-Better-Best（三档菜单）：中间档是你真正想卖的；高档抬锚、低档挡「只要最便宜」的客户。本质不是多做三个包，而是用结构把谈判从「能不能再便宜」改成「你要哪一档结果」。

世界500强实战

Edition 分层：让客户选档，而不是砍价

Salesforce、Adobe 等企业软件常见「Edition」分层：入门档卡死功能边界，专业档塞进多数客户真正要的治理与集成，旗舰档用高级安全 / 多院区 / 专属支持抬锚。GE HealthCare、西门子医疗卖院级方案时，也很少只甩一个总价——他们用「方案层级」让院长在风险与服务等级之间做选择。你偷的不是他们的价位表，是他们的结构：让客户选档，而不是砍价。

亿万富翁致富经

小老板报价像赔罪：先报低，再怕丢单，再加折扣。富老板报价像菜单：贵的那一档写得最清楚、服务边界最硬；便宜档故意「能用但不省心」。狠话一句：你若不能写清楚「这档不含什么」，你就没有资格谈溢价。锚点不是忽悠，是把价值边界说成人话。

落到你的行业 · LIS / 输血 / 十来人厂

示例结构（请按你真实交付力改数字与边界，勿照抄假价）：

LIS 三档（结果导向）

基础档
单院检验流程上线 + 核心报告闭环；不含仪器全对接、不含多院区；适合「先跑起来」。
标准档（主推）
核心闭环 + 主流仪器对接包 + 质控 / 危急值关键路径 + 90天稳定期响应；用「少差错、少扯皮」的结果语言报价。
旗舰档
标准档 + 多院区 / 集团口径 + 专属驻场窗口期 + 年度优化复盘；锚给「怕出事、要可审计」的经济买家。

输血三档

基础档
发血闭环与关键追溯。
标准档（主推）
闭环 + 与 HIS / LIS 关键接口 + 近效期 / 不良反应关键预警路径。
旗舰档
标准档 + 多院区血库协同 + 合规迎检材料包 + 季度演练陪跑。

十来人厂铁律：旗舰档不是「功能更多」，是「风险更低、响应更硬、边界更清」。标准档必须能用现有编制扛住；扛不住就不要印在菜单上。

今日必做 · DO TODAY

1）选 1 个正在跟的 LIS 机会 + 1 个输血机会（或各一个假想但角色真实的目标院）。

2）各写一页三档菜单：档名、卖的结果（3条内）、明确不含（至少2条）、建议对谁讲（对应决策链角色）。

3）标准档旁标注：若对方开口要折扣，你准备让的是「范围」还是「价格」？（只许选一个主策略）

拷问：你现在的报价单，是「人天×单价」，还是「结果档×边界」？若还是前者，今天的菜单写完之前，禁止再口头报低价。

开拓风暴 · MIND STORM

小切口：县域二级医院检验科「报告时效投诉」

AI 会吃掉：重复配置、简单对接文档草稿、初级巡检话术。更值钱：现场流程裁决、与经济买家的风险语言、可审计的责任边界。导师先给 2～3 条可起步路径——你回聊天里选边。

路径 A · 报告时效诊断包（轻咨询 + 小工具）

起步：2周驻场抽样 + 瓶颈图 + 三档改进菜单。
赚钱：诊断费入口，标准档落地改造。
冲富：低（易被大厂免费附赠）。
陷阱：只交 PPT 无系统抓手，难续费。

路径 B · 「危急值 + 时效」双结果包（嵌入现有 LIS 交付）

起步：在标准档菜单里加可度量 KPI。
赚钱：项目溢价 + 季度复盘费。
冲富：中（可复制到多院）。
陷阱：KPI 写死却无数据源，变成自己挖坑。

路径 C · 多院区质控协同订阅（偏旗舰）

起步：先做单集团试点。
赚钱：年费订阅。
冲富：高（但销售周期长）。
陷阱：编制被订阅制拖死；没产品化就别碰。

选边追问：若你只能押一条，未来 90 天押 A / B / C 哪条？为什么？（回聊天里选边）
