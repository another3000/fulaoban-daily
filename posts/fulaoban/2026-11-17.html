纪要闸门：上了会不等于写入纪要

2026.11.17

周二 · 上海

对照计划 · 第1个月第1周 · 定位与报价 · 课次20 · 催交纪要闸门 · 不硬开第2周

作业回看 · HOMEWORK CHECK

今天仍无可批作业。昨天刚加了「上会闸门」，纸仍空（即便你今天一并交出首发包、回执条、传阅条和上会条，会后或会前预置也还没有纪要原句、决议性质和会后责任人期限）。七格全红灯空：①L1结果包 ②L2决策链 ③L3三档菜单 ④L4止损/让步 ⑤L5里程碑+人情 ⑥一页上场版 ⑦证据包P1～P4。今日课题不是重开上会细则 / 传阅闸门 / 回执闸门 / 首发仪式 / 出门证三绿，而是给上会加一把「纪要闸」——上了会不等于写入纪要。没首发就谈不上回执，没回执就谈不上传阅，没传阅就谈不上会，没上会就谈不上纪要。会还没开，也要先交预置版纪要条。第1周须闭环；今天禁止硬开第2周。

社论导读 · EDITORIAL

昨天把上会闸拍在桌上：没有会名、日期、议题原句和宣读人，就别假装已经在走院内程序。「等开会再说」「我提一嘴」「已经排上了，你等通知」不算上会。今天是周二。即便你已经要到了排期（更多人连首发包都还没交），下一个自我安慰会准时上门：「会上大家都点了头；原则上同意；先按这个做起来，纪要还没出来；会上没人反对就算过了；纪要是院内公文，你一个供应商催什么纪要。」

周二上午几乎是标准剧本。会开过了（或小李告诉你「已经开过了」），他会后回：「会上大家没意见，你先做起来吧，纪要院办还在整理。」或者：「原则上同意，细节会后再说。」再防你一步：「纪要是内部文件，出来了我口头跟你同步就行。」这句话听起来像决议已经形成，实际是在用「口头同意 / 没人反对」冒充书面纪要。牌面是议题进了会；牌底是两周后老张可以说「我没答应那三句，纪要里也没有」，小王可以说「付款节点会上没定」，院办可以说「那次会只是通气」——你口袋里只有小李一句「大家都点了头」，甚至已经按口头表态派人进场、开始垫资。

有人会自我安慰：「都上会了就别再催纪要，要公文显得像供应商在指挥院办；口头同意给面子就该先做。」咨询与企业软件售前有一条纪律叫 Minutes Gate / Decision Record（纪要闸 / 决议记录），还有 Documented Decision（书面决议）：议题上了议程、会上点了头，不等于三句绿句已经写进可转发的纪要原句。你要偷的不是公文系统，而是纪律：

「已上会 ≠ 已入纪要；没有纪要原句、决议性质和会后责任人期限，就别假装『会上已经定了』，更别按口头表态开工。」

— 亿万富翁导师 · 本周金句

今日课题 · BRIEF

纪要闸门（Minutes Gate）——正式上会之后，要书面纪要：纪要原句 + 决议性质 + 会后责任人与期限

为 LIS 标准档或输血标准档至少一线：
1. 若仍无首发包：今天仍须先交「三绿最小包首发」。没首发就谈不上回执，更谈不上传阅、上会和纪要。
2. 若仍无回执：补回执条，对方书面点名至少两句绿句；禁止「嗯 / 收到了 / 回头再对」。
3. 若仍无传阅：补传阅条，不能只传给小李，除小李外至少一人书面已阅；禁止「回头说说 / 已经转了你等消息」。
4. 若仍无上会：补上会条五格；禁止「等开会再说 / 我提一嘴 / 已经排上了你等通知」。
5. 再交「纪要条」五格：①会名 + 日期（对得上上会条，禁止「那次会」）；②纪要原句（不能是「LIS事宜已讨论 / 输血建设交换了意见」空筐，须含或附三句绿句）；③决议性质（通过 / 暂缓 / 补材料再议，必须标明哪一种）；④会后动作（责任人具名 + 期限到日）；⑤纪要文本或可转发摘录（公文、纪要页、原句截图；「我口头跟你同步」不算）。
6. 禁止把「原则上同意 / 先做起来，纪要还没出来 / 会上没人反对就算过了 / 我口头跟你同步」当成已形成决议，更禁止在纪要未出时按口头表态开工垫资。会尚未开：今天交预置版纪要条；会后 24 小时按条要摘录；48 小时仍停在「原则上同意 / 先做起来 / 纪要稍后补」则交「已上会未入纪要」记录。路由仍走小李，不私戳院办秘书抢纪要。
7. LIS 或输血至少一线；输血勿把迎检当收款开关；勿编假财报、勿抄示例。
8. 交了红笔批；没交 → homework 继续 pending，第2周继续锁。L1～L5 + 一页上场版 + 证据包继续催交。

拷问：会上「大家都点了头」，或会后小李回「原则上同意，纪要还没出来，你先按这个做起来」「会上没人反对就算过了」——你把它当决议收下并开工，还是请他写清纪要原句、决议性质和会后责任人期限？

商学院硬理论 · Minutes Gate / Documented Decision

Minutes Gate（纪要闸）= 事先约定的「会上对范围句的态度，必须写进可核对的会议纪要：原句、决议性质、会后谁在哪天前做什么」的检查清单。Documented Decision = 决策不靠房间里的点头和会后一句「大家都没意见」，而靠可转发的书面记录。Meeting Minutes 在咨询和董事会治理里不是行政附庸，是会后唯一能被引用的文本。它不是逼你索要机密公文，是反自我欺骗：

1. 已上会 ≠ 已入纪要：议程上有条目，只证明正式讨论过。进度靠「纪要原句里出现了三句绿句或明确附件」证明，不靠「他们点了头」。
2. 「原则上同意」≠ 通过：原则上同意、先做起来、细节会后再说，常常是把冲突推迟，不是锁定档位和付款触发。没有决议性质，就可能被事后解释成「只是通气」。
3. 没写进纪要的口头表态，会后没有强制力：老张改边界、小王不认付款节点、院长砍档，都会说「纪要里没有这句」。你若已经按口头表态开工，等于免费垫资。
4. 纪要是变更的基准：后面要改范围、改档、改触发，比的是「纪要里已经写了什么」，不是「我记得会上好像说过」。

类比（点名思路，勿堆假财报）：咨询顾问在指导委员会后，要在 24～48 小时内发出书面 minutes，确认 SOW 条款被记录为通过、暂缓还是补材料；企业软件销售在资本委员会后，不能只拿冠军用户一句「会上过了」去对 CFO。十来人厂没有售后法务团队替你会后圆——你更需要纪要闸，因为小李一句「原则上同意，你先做起来」，三句绿句可以在会后被改写成完全不同的版本，而你已经派人进场了。第2周大理论等首发包、回执、传阅、上会和纪要交上来、第1周闭环后再开。

世界500强 / 顶级售前实战（可偷的纪律）

像样的咨询公司把「决策会后 48 小时内发出书面纪要，条款必须被标成通过 / 暂缓 / 待补」当成纪律：项目经理不许对外说「会上已经定了」却拿不出 minutes。像样的企业软件售前有 decision log / steering committee minutes check：纪要原句没写范围和商务条件之前，销售被禁止启动实施或宣称「已经批准」。医疗信息化场子更碎：小李一回「原则上同意，你先做起来，纪要稍后补」，你若没有纪要条，两周后老张可以说「我没答应那三句」，院办可以说「那次只是通气」——你只有一句「小李说大家都点了头」，可能还已经垫了人。

再偷一条：要纪要是给小李减责用的，不是你在指挥院办、也不是你在索要机密公文。 小李怕院长会后问「那天到底定了什么」，他只能凭记忆答辩；老张怕自己会上点了头，纪要里却变成另一套范围；院办怕口头表态被供应商拿去当已批准。你要做的，是给小李一份会前就可以用的纪要要项——三句绿句写在原句里或附件里，决议性质勾一项，会后动作有人名和日期。会后他转发一页摘录，不必替你回忆全场。

亿万富翁致富经

钱藏在写进纪要的句子里，不藏在「大家都点了头」里。十来人厂最容易死在一句「原则上同意，你先做起来」：会开过了，议题也宣读了，然后你按口头表态派人进场，纪要两个月后出来，三句绿句一句都没有，付款节点被写成「视进度再定」。富人卖的是有书面决议的范围，不是会上的气氛。你今天若只得意于「已经上会而且大家都没反对」，没有纪要原句，你就还在给医院做免费咨询——而且这咨询已经开始垫资。

行业落地 · 纪要条（今天出门）

格 最低达标 不算
会名 + 日期 与上会条一致，具体到哪一次会的哪一天 「那次会」「上次设备会」「已经开过了」

判定：有首发包+有回执+有传阅（第二人已阅）+有上会条+纪要条五格齐（会未开则为预置版，会后须补摘录）→今天算过纪要闸；只有「原则上同意 / 先做起来 / 大家都点了头 / 我口头跟你同步」→禁止把口头表态当成已经形成决议，禁止开工垫资。

虚拟院：会后小李回「原则上同意，纪要还没出来，你先按这个做起来 / 会上没人反对就算过了 / 纪要是内部文件，我口头跟你同步」——你若把这句当决议并派人进场，两周后纪要出来没有三句绿句，老张改边界，小王不认触发，压力转成你已经垫进去的人天。掏出纪要条：「李哥，会上怎么定我听您的，我不直接找院办要公文。请按这五格写一会名和日期、一条含或附三句绿句的纪要原句、写明是通过、暂缓还是补材料再议，并写清会后谁在哪天前做什么。完整公文您可以不发我，转发原句摘录或截图就行。这样您被院长问那天到底定了什么时，能对上书面口径，不必凭记忆答辩。」纪要挡「原则上同意、你先做起来」；没有纪要原句，就只能赌会后还记不记得你，而且可能已经在垫资。纪要走小李路由，不私下绕过他去戳院办秘书。输血绿句可写合规闭环怎么验收，不可把「迎检通过」写成收款开关，也不可写进纪要原句当触发。

纪要原句示例（可改写，勿原文抄成作业）：LIS「×年×月×日设备管理委员会审议 LIS 标准档结果包（附件三绿）：范围按第 1 句验收，档位按第 2 句锁定，付款触发按第 3 句执行。决议：通过。会后：信息科小李于 × 月 × 日前将三绿作为附件随纪要归档；供应商按里程碑第 1 节点提交预付触发证据，不得在纪要发出前实施进场。」输血「×年×月×日院长办公会审议输血标准档结果包（附件三绿）：闭环验收按第 1 句，档位按第 2 句，里程碑付款按第 3 句；不含以迎检通过为收款条件。决议：通过 / 或补材料再议（写明补哪句）。会后：输血科主任老张于 × 月 × 日前确认附件三绿与纪要原句一致。」

厚黑人情 · 老油条 · HOUHEI

对方回「原则上同意」「先按这个做起来，纪要还没出来」「会上没人反对就算过了」或「纪要是内部文件，我口头跟你同步」

本课角度：绑纪要闸门 / Minutes Gate / 上了会不等于写入纪要。小李说「原则上同意 / 先做起来纪要稍后补 / 会上没人反对就算过了 / 我口头跟你同步」——牌底是用口头同意代替书面纪要。合法可试。禁止行贿、回扣、假票、围标。

一句招 · 一句戒

招：把「请把三句绿句写进纪要」译成「帮小李省会后被院长问『那天到底定了什么』时对不上口径」——会前把纪要要项交给他，会后他只需转发原句，不必凭记忆答辩。你不是在要机密公文，是在给入口人准备可对口径的书面摘录，让他少在院长面前靠回忆打仗。

戒：不要把「原则上同意 / 先做起来 / 会上没人反对就算过了 / 纪要还没出你先开工 / 我口头跟你同步」当成已形成决议。没有原句、决议性质和责任人期限，就是还没过闸。也不要自己起草一份「我方理解会上已原则同意标准档」群发给全院，或绕过小李去追院办秘书抢纪要——那是砸他的院内面子，还可能把口头理解写成对方事后必须否认的版本。可以温柔、可以只要摘录不要完整公文，不能一边说会上已经定了，一边按口头表态派人进场。

可立刻试：写纪要条时把这句抄在页脚。上午若真有人回「原则上同意，你先做起来」，直接用：「李哥，会上怎么定我听您的，我不直接找院办要公文。请在纪要里写清会名和日期、三句绿句原句（或『见附件三绿，会上已宣读并写入纪要』）、是通过、暂缓还是补材料再议、会后谁在哪天前做什么。完整公文您可以不发我，转发原句摘录或截图就行。这样您被院长问那天到底定了什么时，能对上书面口径。」关系越好越要走他做路由。催的不是「把内部公文给我」，是「别让他会后被问到那天定了什么却对不上书面口径」。

讨论靶场 · DEBATE

反向角度：有人说「要纪要太正式，伤感情，口头同意就该给面子先做；纪要是院内公文，供应商不该催，催了像在指挥院办」——你何时承认他们说对了？什么场景必须硬刚书面原句？请用你真实被「会上说好了、会后纪要没有、对方改口、你已经进场」套住的一单说明：当时若有纪要条写清了原句、决议性质和责任人期限，哪一句能挡住「我没答应那三句 / 那次只是通气」？（引导：关系越好越要走入口人把原句写入纪要，会后改口的代价往往先砸在小李头上；「给面子先做」会做成对你不利的范围，而且是你在垫资。）
